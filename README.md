# Task Manager CLI

Консольный менеджер задач на Python с сохранением данных в JSON.

## Возможности

- Добавление новых задач.
- Просмотр списка задач.
- Отметка задач как выполненных.
- Удаление задач.
- Проверка пользовательского ввода.
- Автоматическое сохранение изменений в JSON.
- Загрузка задач при запуске программы.

## Технологии

- Python 3
- JSON
- pathlib

## Как запустить

1. Установить Python 3.
2. Скачать проект.
3. Открыть терминал в папке проекта.
4. Запустить программу:

```bash
python main.py
```

Дополнительные библиотеки не требуются.
