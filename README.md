# ✅ Task Manager

**Task Manager** — приложение для управления личными задачами на Python с консольным и графическим интерфейсами.

Проект разработан для практики Python, работы с JSON, обработки пользовательского ввода и создания GUI на Tkinter.

## ✨ Возможности

- ➕ Добавление новых задач
- 📋 Просмотр списка задач
- ✅ Отметка задач как выполненных
- 🗑️ Удаление задач
- 💾 Автоматическое сохранение данных в JSON
- 🔄 Восстановление задач после перезапуска
- 🌙 Графический интерфейс с тёмной темой

## 🖥️ Интерфейс

Приложение использует Tkinter и включает поле ввода, список задач и кнопки управления.

Выполненные задачи выделяются зелёным цветом.

*Скриншот приложения добавим позже.*

## 🛠️ Технологии

- **Python 3** — основной язык разработки
- **Tkinter** — графический интерфейс
- **JSON** — хранение задач
- **pathlib** — работа с путями к файлам
- **Git** — контроль версий

Все библиотеки приложения входят в стандартную библиотеку Python.

## 🚀 Запуск

1. Установите Python 3.
2. Склонируйте репозиторий:

```bash
git clone https://github.com/symf0ny/task-manager-cli.git
```

3. Перейдите в папку проекта:

```bash
cd task-manager-cli
```

4. Запустите графическую версию:

```bash
python gui.py
```

Для запуска консольной версии:

```bash
python main.py
```

## 📁 Структура проекта

```text
task-manager-cli/
├── main.py        # Консольная версия
├── gui.py         # Графический интерфейс
├── README.md      # Описание проекта
└── .gitignore     # Исключения Git
```

Файл `tasks.json` создаётся автоматически при сохранении задач и не включается в репозиторий.
